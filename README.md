# Skywarrior

**MYTHOS — War for the Ruined World**

A self-contained, single-file HTML5 flight combat game. Runs entirely in the browser with touch and keyboard/mouse controls — no build step or server required.

## Run
Just open `Skywarrior.html` in a modern browser (Chrome, Safari, Firefox).

## Project Structure
```
Skywarrior.html   # Full game: markup, styles, and logic in one file
```
